## WEEK 3 (27 November 2026)
### Inisialisasi Proyek dan Pengembangan Tampilan Awal

Pada minggu ketiga, pengembangan awal aplikasi **GigsHub – Event, Concert, & E-Ticket Companion App** mulai dilakukan menggunakan Android Studio.

**Pekerjaan yang Telah Diselesaikan:**

- Menggunakan Kotlin sebagai bahasa pemrograman dan Jetpack Compose untuk membangun antarmuka aplikasi.
- Menyusun struktur package proyek berdasarkan arsitektur MVVM.
- Membuat struktur package untuk Core, Data, Domain, Feature, dan Dependency Injection.
- Menentukan konsep desain antarmuka dengan tema Coffee Aesthetic.
- Membuat palet warna utama aplikasi, yaitu Espresso, Coffee Brown, Warm Mocha, Latte, Cream Beige, dan Ivory.
- Mengimplementasikan tema aplikasi menggunakan Jetpack Compose Material 3.
- Membuat tampilan awal aplikasi dengan teks sambutan "Welcome to GigsHub!".
- Berhasil menjalankan aplikasi pada Android Emulator.

**Teknologi yang Digunakan:**
- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- Android Studio

**Pekerjaan yang Sedang Dipersiapkan:**
- Konfigurasi dependency Gradle.
- Persiapan Navigation Compose.
- Persiapan Retrofit dan OkHttp untuk integrasi REST API.
- Persiapan Coroutines, Kotlin Serialization, Coil, dan ViewModel.
